## 3) M1 工程落地时建议同步归档的“证据位置”

本包不包含真实工程执行证据（需要团队现场产出）。建议你们在工程仓库或网盘建立：
- `evidence/M1/CI/`（pipeline 截图/链接）
- `evidence/M1/OpenAPI/`（codegen 产物、lint 报告、contract tests 报告）
- `evidence/M1/Auth/`（STAGING 录屏、CSRF 校验记录）
- `evidence/M1/Security/`（SCA/Secret/SAST/DAST 报告）
- `evidence/M1/Concurrency/`（412/428 复现）
- `evidence/M1/Gateway/`（/api→/v1 rewrite 与打点日志）
